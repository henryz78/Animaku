# 本机缓存与下载

播放页的“缓存 / 下载剧集”可以多选当前片源、当前线路的剧集。设置页和顶部菜单都有“缓存与下载中心”入口。

- 视频保存在当前设备的 IndexedDB，按网站账号区分。没有新增 D1 视频表、R2 存储或下载代理服务。
- 自动缓存默认关闭。开启后保存当前集之后的 1–5 集，默认 2 集；默认视频空间上限为 2 GB，也受浏览器实际配额限制。
- 当前视频等待缓冲或向前缓冲少于 3 秒时，后台媒体下载暂停。缓冲达到 8 秒并稳定 3 秒后继续；用户暂停当前视频时也可继续缓存。
- 手动选集的弹幕选项默认不勾选。当前集保留已选弹幕池的内容，其他集按官方集数匹配，必要时尝试 B 站。没有可靠结果会提示，视频仍可播放。再次勾选可以给已有视频补存弹幕，无需重下视频。
- 在网站播放器观看缓存，记录保存在本机；联网并登录同一账号后补同步。导出到外部播放器后的进度无法读取。

## 缓存、续传与清理

队列顺序下载，每次一集。可暂停、继续、重试和批量删除。关闭网页后暂停，重新打开后手动继续；不承诺浏览器关闭时仍在后台下载。

MP4 按 4 MB 分块保存。源站支持正确字节范围且提供文件校验标识时，刷新后可以从已完成的块继续。文件校验、地址或 HLS 播放列表发生变化时会重新下载，避免混合不同版本。源站不支持续传时也会重新下载。

空间不足时自动清理最久未使用的、已完成的自动缓存。手动缓存会保留，正在播放或导出的缓存受保护。没有可清理内容时，新下载停止并提示。删除缓存不删除观看历史，也不会删除已导出到系统目录的文件。

首次缓存会保存网站页面与播放器所需文件，支持断网重新打开 `/offline`。离线入口只使用此前联网登录留下的本机账号标识，不赋予管理权限；在线服务明确拒绝登录或用户退出时，该标识会清除。

浏览器仍可能回收网站数据，尤其在空间不足或隐私模式下；持久存储申请不能保证永远保留。清理浏览器网站数据会移除本机缓存。数据备份 JSON 不包含视频。

## 支持的格式

| 片源 | 本机播放 | 文件导出 |
| --- | --- | --- |
| 普通 MP4 | 支持 | MP4 |
| 完整的 HLS 点播列表，含常见 TS / fMP4 | 支持 | 分片包 ZIP；符合条件的 TS 可直接合并 |
| 标准 AES-128 HLS | 保存密钥与分片供播放器解密 | 分片包 ZIP，保留原加密信息 |
| 直播、DRM、独立音画轨的 HLS master | 当前不支持，会提示换源 | 不支持 |

分片包包含本地 m3u8、初始化文件、密钥和分片，需要支持该格式的播放器。此版本没有重新编码或将 HLS 转成 MP4。ZIP 暂不支持 ZIP64（单包约 4 GB 上限）。弹幕可单独导出 XML，不会烧录在视频画面中。

Chrome 可直接流式写入用户选择的系统文件。其他浏览器通过本机 Service Worker 的附件流下载；请保持页面打开。下载完成与磁盘剩余空间仍由浏览器管理。

## Cloudflare 用量

本机播放和导出读取设备数据，不下载第二份源站视频。直连 CDN 的媒体请求不经过 Worker。需要防盗链、登录票据或跨域代理的片源会增加 Worker 请求与 CPU 用量；此版本复用现有受控代理，没有增加任意 URL 代理。首次缓存页面会下载网站静态文件。

## 验证

相关 Node 测试位于 `apps/web/src/offline/hls.test.ts`，同时回归播放器、集数匹配、历史记录和云端同步。

正式前端构建后，可用已有的 Playwright 运行 `scripts/test-offline.mjs`；外部安装可通过 `PLAYWRIGHT_MODULE_PATH` 指定。测试使用本机生成的短 MP4/HLS 和临时接口，浏览器与 HTTP 测试服务会在结束时关闭。产物位于忽略的 `.tmp-offline-e2e` 目录，不上传用户内容。

Windows WebKit 测试已确认媒体可保存。其原生 HLS 解码不可用，原生 MP4 请求还会绕过 Service Worker 到达网络；因此没有把 Safari 离线播放记为通过。测试还遇到 Playwright 的 WebKit 离线导航问题（microsoft/playwright#42775），用关闭测试源站连接进行对照。实际 iPhone / macOS Safari 的离线播放与导出尚需真机确认。

### 线上实测（2026-10-07）

使用普通测试账号，在 Codex 内置 Chromium 浏览器访问已部署站点，未使用外部浏览器测试脚本。

- 《奇诺之旅》第 1 集，cycani 源：完整保存 332,562,032 字节的 MP4；模拟断网并刷新 `/offline` 后仍能播放、拖动进度。用户已将导出的 MP4 保存到下载目录，并确认文件可以播放。
- 已有视频补存 4,282 条弹幕时，没有重新请求源站视频；断网播放时可以显示已保存的弹幕。
- 《葬送的芙莉莲》第 1 集，moonci 源：完整保存 HLS 的 306 个条目，共约 448.1 MB。两次暂停、刷新、继续均保留已存分片；断网刷新后正常播放，跳到第 21 分钟后的分片仍由本机 Service Worker 返回。再次刷新可从暂停位置续播。页面提供 TS 和 ZIP 导出入口，但尚未把此样本的导出文件保存到磁盘并用外部播放器验证。
- 离线播放超过现有的 15 秒有效观看门槛后，暂停、关闭播放器、刷新仍可续播。恢复联网后，D1 中的观看位置与离线暂停位置一致，本机待同步记录在服务端确认后清空。
- 测试发现离线播放器缺少作品和集数标识，导致共享播放器没有发送进度回调；已补齐这两个参数并重新验证本机记录、刷新续播和云端同步。
- 修改提前保存集数、空间上限后刷新，设置保留；测试结束恢复默认的 2 集、2 GB，自动缓存保持关闭。

这些结果只覆盖实际测试的片源和 Chromium 环境，不代表所有片源、格式及 Safari 均已通过。MP4 测试期间源站更换了 CDN 地址，界面明确提示并重新下载；因此没有把该次恢复下载记为从原字节位置续传成功。
